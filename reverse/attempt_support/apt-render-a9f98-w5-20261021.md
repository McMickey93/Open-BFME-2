## New target fact: WB's four sentinel locals are `a` and `b`

WB render initialises `[ebp-0x10..-4]` from the global 0x1dd08e0 right after the timer start. The
only other uses are `lea [local_10]` and `lea [local_8]` passed to the segment draw call, so these are
the line case's `V2 a, b`, each component set to one scalar sentinel. Retail has no such stores.

- **Sentinel ctor kept in release** (all six spellings: aggregate init, derived `V2S` ctor, V2 ctor
  with init list or body assignments, chained `X = Y = g`; × extern float or const float × k 0..7):
  the dead stores survive (a and b escape to the call). Best 67 diffs. **Disproven.**
- **Empty release ctor `V2() {}`** (the natural reading if the sentinel is `#ifdef _DEBUG`): best14
  per-site config gives 22 at k=4. Coordinate descent restarted from it reaches 20. Worse than
  without the ctor, but the ctor is plausible source. If a later seat finds the per-site mechanism,
  re-test the ctor on top.
